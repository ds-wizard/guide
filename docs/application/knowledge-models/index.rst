Knowledge Models
****************

Knowledge models define the questionnaires used in projects. The :doc:`list/index` contains published versions; the :doc:`editors/index` is where we create and change them.

After publishing a new model version, existing projects keep their selected version until we :doc:`migrate them </application/projects/list/migration>`.

Use :doc:`secrets` for credentials needed by API integrations.
