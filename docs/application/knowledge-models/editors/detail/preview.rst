Preview
*******

We can use the :guilabel:`Preview` tab to quickly see what the resulting questionnaire would look like. If there are any :ref:`question tags<question-tag>` set up, we can also try different combinations of selected tags and observe the changes in the questionnaire.

.. figure:: /_static/screenshots/5.0/km-editor-preview.png
    :figclass: guide-screenshot
    :alt: Knowledge Model Editor preview in DSW 5.0
    :width: 760

    Knowledge Model Editor preview.

If we want to develop the knowledge model together with the document template, we can use the :guilabel:`Save preview values` button. This will save the current preview answer values to the knowledge model and make them visible in the :ref:`document template editor<document-template-editors>`.
