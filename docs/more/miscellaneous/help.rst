.. _help:

Get Help and Report an Issue
****************************

Open our name or avatar in the main navigation and choose :guilabel:`Report issue`. The dialog shows the support website and email configured for the instance. Follow one of those links to report the problem; the dialog itself does not send a report.

Include what we tried to do, the steps to reproduce the problem, the expected result and the error shown. Add the instance address, browser and application version from :doc:`/application/profile/about`. Check screenshots and logs for passwords, API keys or private data before sharing them.

If we cannot sign in, contact the instance administrator using the support details provided by our organization. Administrators configure the links under :doc:`/application/administration/settings/system/privacy-and-support`.

For community questions, join the `DSW community on Discord <https://discord.com/invite/MW3H9tdMcT>`_.
