Upload a translation
********************

#. In :guilabel:`Settings` → :guilabel:`Translations`, choose :guilabel:`Application` or :guilabel:`Emails`.
#. Choose the upload action and select the PO file.
#. Click :guilabel:`Upload`. If warnings are shown, review the language, version and reported differences before confirming. Without warnings, the upload completes automatically.
#. Enable the uploaded language in the list before offering it to users.

An upload that replaces an official language turns it into a custom translation. Keep your PO file so it can be maintained for later message changes.
