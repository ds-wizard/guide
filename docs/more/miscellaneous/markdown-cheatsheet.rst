Markdown Cheatsheet
*******************

Many text fields accept Markdown. Use the field's preview to check the result.

.. code-block:: markdown

   # Heading
   ## Subheading

   **Bold** and *italic* text. ~~Strikethrough~~

   - First item
   - Second item

   1. First step
   2. Second step

   > A quotation

   [Link label](https://ds-wizard.org)
   ![Meaningful image description](https://example.org/image.png)

   `Inline code`

   ---

   | Name | Value |
   | --- | --- |
   | Dataset | 123 |

   - [x] Completed task
   - [ ] Remaining task

Use fenced blocks (three backticks on separate lines) for longer code examples. Available rendering can depend on where the field is displayed, including the document template used for an export.
