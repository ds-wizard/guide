DSW Registry
************

The Registry connection lets us import published knowledge models, document templates and translations. Open :guilabel:`Settings` → :guilabel:`DSW Registry` with :guilabel:`Manage Settings`.

Enable the connection and provide an API key from your `DSW Registry account <https://registry.ds-wizard.org/>`_. Save the settings, then check the import pages for available content.

A Registry API key is separate from an instance API key. Create and revoke Registry keys in the Registry account. The earlier organization-registration and confirmation-token workflow is replaced by personal accounts and API keys.

For content imports, see :doc:`/application/knowledge-models/list/import` and :doc:`/application/document-templates/list/import`. Application and email languages are managed under :doc:`/application/administration/settings/translations/index`.
