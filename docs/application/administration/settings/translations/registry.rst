Import Translations from the Registry
*************************************

Open the application or email translation list and choose the Registry import action. Select a translation available for the running DSW version and import it.

The Registry offers translations compatible with the running application version. If the language is already installed, review the replacement warning before confirming. Enable the imported language before offering it to users.

To maintain your own wording, use :doc:`upload` and keep the custom PO file.
