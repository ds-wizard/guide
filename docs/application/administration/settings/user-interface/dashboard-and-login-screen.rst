Dashboard & Menu
****************

Here we can configure announcements shown on the dashboard after sign-in and add custom menu links.

For each link, enter a title, URL and icon. Use the move controls to change its position, and select :guilabel:`New window` if the destination should open separately. The linked page should be accessible to the people who will use it.

The login screen is configured separately in :doc:`/application/administration/settings/user-interface/login-screen`.

Announcements
=============

Choose :guilabel:`Add announcement`, select its **Level** and enter **Content** using Markdown. The levels are **Info** for general information, **Warning** for notices requiring attention, and **Critical** for urgent notices. More than one announcement can be configured.

Announcements in Dashboard & Menu appear above the dashboard content after sign-in. Configure an announcement separately in Login Screen if it should also be shown before sign-in. Changes to one section do not automatically change the other.
