.. _plugins:

Plugins
*******

With :guilabel:`Manage Settings`, open :guilabel:`Settings` → :guilabel:`Plugins` to enable installed plugins and configure their settings. Installed plugins and available fields depend on the instance.

Plugins can extend questionnaire questions, integrations, project actions, document actions and settings. A plugin can also provide :doc:`personal settings </application/profile/settings/plugins>` for each user.

Plugin installation is configured by the deployment administrator; see :doc:`/more/self-hosted-dsw/configuration/plugins`.
