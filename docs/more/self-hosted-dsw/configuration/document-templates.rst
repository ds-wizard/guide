Document Templates
******************

We can customize the content and styling of document templates. HTML and CSS knowledge is required, and for doing more complex templates that use some conditions, loops, or macros, knowledge of `Jinja templating language <https://jinja.palletsprojects.com/en/stable/>`__ (pure Python implementation) is useful. For more information, please read :ref:`the following section<document-template-development>`.
