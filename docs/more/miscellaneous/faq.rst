Frequently Asked Questions
**************************

What is the difference between a knowledge model, a project and a document template?
====================================================================================

A knowledge model defines the questions. A project contains our answers to those questions. A document template turns the answers into a document, such as a data management plan. See :doc:`/about/introduction/index` for an introduction to these three parts.

Are my answers saved automatically?
===================================

Answers in the questionnaire are saved automatically. Check the connection and any saving errors before closing the page. Forms such as project settings and sharing have their own :guilabel:`Save` button.

We can return to the project from the :doc:`project list </application/projects/list/index>` after signing in to the same DSW instance.

How do I find questions I have not answered yet?
================================================

Open :guilabel:`Unanswered` in the questionnaire toolbar to see the questions that still need answers. If the knowledge model defines phases, the list follows the current phase. Select a question to open it. Questions made irrelevant by earlier answers are not included. See :ref:`unanswered-questions`.

How do I download my plan as PDF or Word?
=========================================

In the project's :guilabel:`Documents` tab, choose :guilabel:`New document`, enter a name, and select a compatible document template and format. After generation finishes, download the document from its row. The available formats depend on the selected template; ask an administrator if the format we need is missing. See :doc:`/application/projects/list/detail/documents`.

Why is the questionnaire not in my interface language?
======================================================

The interface and questionnaire have separate language settings. :doc:`User settings → Language </application/profile/settings/language>` changes the interface. To change the questionnaire language, choose an available knowledge model translation in the :doc:`project settings </application/projects/list/detail/settings>`. That translation must be available for the project's knowledge model.
