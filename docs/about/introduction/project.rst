.. _project:

Project
*******

A project contains our answers to a questionnaire. It is based on a :ref:`knowledge model<knowledge-model>` and uses :ref:`document templates<document-template>` to generate documents.

Projects are fully collaborative, so we can share them with other researchers and work together.


Questionnaire
=============

The questionnaire is where we fill in our answers. It is generated from the selected knowledge model and shows the questions relevant to our previous answers. It also provides FAIR metrics, comments, TODOs and version history.


:ref:`Learn how to work with the questionnaire →<project-questionnaire>`

Documents
=========

We can generate a data management plan from our answers using a document template. These documents are saved within the project. We can create documents with different templates and formats. We can also set up a default document template for the project and quickly see a preview of the document.


:ref:`Learn how to work with the documents →<project-documents>`
