Getting Started
***************

DSW helps researchers and data stewards prepare data management plans. A knowledge model defines a questionnaire, a project stores the answers, and a document template turns those answers into a document.

Start with :doc:`overview` to see how these parts fit together. Researchers can then :doc:`create a project </application/projects/list/create>`. Content authors can start with a :doc:`knowledge model <knowledge-model>` or :doc:`document template <document-template>`.

The menu and available actions depend on our permissions and the instance settings. Open our name or avatar in the main navigation for personal settings, appearance, help and version information.
