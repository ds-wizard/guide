Create a User Group
*******************

Open :guilabel:`User Groups` and choose :guilabel:`Create`. You need **Create User Groups**.
Enter a name and, optionally, a description. Choose whether the group is public or private, then save it.

Other signed-in users can see a public group. A private group is visible to its members and authorized administrators.

Continue with :doc:`/application/user-groups/detail` to add members and owners.
