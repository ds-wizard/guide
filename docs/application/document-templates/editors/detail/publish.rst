Publish
*******

Choose :guilabel:`Publish` in the editor and review its metadata. Return to :guilabel:`Settings` if anything needs correcting, then confirm publication.

After publishing, the template is available in the library where it belongs and the editor is closed. We can create a new editor to develop another version.

Before publishing, we should test each format with example projects and translations to check the generated documents. See :doc:`/more/development/document-templates/tdk` for local checks.
